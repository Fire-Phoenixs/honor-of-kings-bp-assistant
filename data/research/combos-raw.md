# 强势组合调研（原始）

> 调研范围：王者荣耀「强势组合 / 阵容体系」，覆盖 2 人小组合、3-4 人小体系、5 人完整阵容三类，供五排 BP 平台做数据补强。
> 调研时间：2026-10-24。版本参考：S40～S45（正文已标注各条来源的发布时间，2025 及更早内容均注明版本/年份）。
> 英雄分路写法：对抗路 / 打野 / 中路 / 发育路 / 游走。
> 置信度口径：high = 至少 2 个独立来源；medium = 1 个来源；low = 单源且细节不足 / 含经验推断（已注明）。

## 1. 刀枪炮（消耗体系，5 人阵容）
- 核心英雄：百里守约（发育路）、墨子（游走 / 可走中路）、沈梦溪（中路）、暗信·李信（对抗路）、自由打野位（任选强势灵活打野）
- 可替换位：墨子被 ban 可用大乔（小控制更多更频繁）；打野位为「配角」，选强势、刷野快、灵活的即可
- 体系类型：远程消耗 + 视野压制 + 边路牵制
- 强势期：前期到中期，来源原文称「没有明显的弱势期」
- 为什么强：墨子二技能一炮定身 → 守约二技能稳定命中，脆皮半管血直接没；沈梦溪大招 + 梦魇之牙疯狂挂重伤，对面选蔡文姬、桑启这类奶妈也奶不回来；守约与墨子的一技能叠加视野，掌控力拉满，对面想偷人/绕后很难；暗信给边线持续压力，逼对面分人，正面凑不齐五个人冲消耗三人组
- 反制思路：远程强开最有效（后羿大招这类超远距离开团配合集火秒人）；消耗三人组身板都脆，被一群人贴脸黏住就难打；务必先清掉守约/墨子的视野点，再绕后包夹
- 来源：https://bbs.hupu.com/641085439.html（2026-07-20）
- 置信度：medium（1 源；守约+墨子双人形态另见第 15 条，2 源互证）

## 2. 朵莉亚刷大·双边体系（5 人阵容）
- 核心英雄：蚩奼（发育路）、曹操（对抗路）、武则天（中路）、铠（打野）、朵莉亚（游走）
- 可替换位：发育路 狄仁杰 / 艾琳；打野 宫本武藏 / 杨戬；对抗路 哪吒 / 狂铁；中路 女娲 / 甄姬；游走 盾山 / 少司缘
- 体系类型：无限大（刷新大招）+ 双前排 + 双 C
- 强势期：前期偏弱需安稳发育，4 分钟拿完暴君后开始滚雪球，中后期最强
- 为什么强：朵莉亚大招可以给队友刷新大招——前期给铠 / 曹操 / 蚩奼刷大提高作战强度，后期给武则天刷出双大，团战能力极强；曹操、蚩奼都有近战 + 远程两种攻击手段且适配半肉，既能当双前排也能当双 C，即便没有传统大肉，团队坦度也均衡；坑点：前期不要给武则天刷大，否则武则天大招会被封印约 100 秒
- 反制思路：这套前期强度一般，对面抢前期（强开野区、4 分钟前逼团）可以压制；朵莉亚路人局不强势，靠的是阵容配合，ban 掉朵莉亚或打散辅助-法师连体节奏即可
- 来源：https://forum.cdo.oppomobile.com/read.php?tid=14014057&fid=13064（2025-12-06，2026-02-18 编辑）
- 置信度：medium（1 源，2025-12 版）

## 3. 双坦不死流（双前排 + 控制链，5 人阵容）
- 核心英雄：夏侯惇（对抗路）、白起（打野）、海月（中路）、莱西奥（发育路）、孙膑（游走）
- 可替换位：中路需「抢线快」的法师（来源点名 海月 / 沈梦溪 / 周瑜）；射手位莱西奥为推荐首选
- 体系类型：双前排 + 控制链 + 四保一（保射手）
- 强势期：4 级前是弱势期（白起、夏侯惇都吃大招）；白起做出两件套 + 孙膑出到痛苦面具进入第二个强势期；10～18 分钟最无解，建议此阶段结束比赛
- 为什么强：双前排可以互相拆火，一个被集火另一个立刻接管，容错率远高于单前排；白起大招嘲讽 + 多段控制负责开团，夏侯惇对线稳、二技能补野怪伤害发育快；孙膑二技能加速让双坦更容易威胁后排，配高配抬血让两个坦克变成「不死战神」；莱西奥在大后期有双前排保护安心站桩输出
- 反制思路：必 ban 吕布（后期真伤牢牢限制双前排）与庄周（群体解控让白起大概率零作为）；拖到 20 分钟以后双方装备成型，靠频繁带线牵制、抓落单点
- 来源：https://game.xiaomi.com/viewpoint/1487321501_1673950777446_13（2023-01-17，S30 版本）
- 置信度：medium（1 源，2023 版；体系框架仍成立，但英雄强度已变，用前需按当前版本核验）

## 4. 带线团战结合阵容（边路牵制流，5 人阵容）
- 核心英雄：梦奇·AD（对抗路）、亚连（打野）、暃（中路，来源如此标注，存疑）、敖隐（发育路）、桑启（游走）
- 可替换位：对抗路可换暃；辅助硬辅可选白起，软辅即桑启
- 体系类型：边路牵制 + 高机动转线
- 强势期：全程，靠转线拉扯，无极端偏科短板
- 为什么强：五个位置都能带线也能参团——梦奇被动自带双抗、一技能护盾，带线 1 打 2 能撑到支援，参团还能大招击飞开团；亚连自带突进 / 霸体 / 真伤，带线能脱身，参团大招锁后排或给队友套盾；暃靠墙体高机动转线支援，带线被包夹也能脱身；敖隐有龙魂稳定输出、大招上天保命兼进场，不必一直跟辅助连体；桑启二技能飞草丛转线极快，高频治疗稳血线
- 反制思路：这类阵容最怕「两个以上纯单带英雄」的模仿版（正面永远少人）；针对梦奇、敖隐的对线期强度压制发育；用视野抓带线点、逼正面 5v4
- 来源：https://www.sohu.com/a/1038623402_122836948（2026-06-19）
- 置信度：medium（1 源，2026-06；「暃走中路」与常规分路不符，已在存疑一节标注）

## 5. 快攻拉扯流（5 人阵容）
- 核心英雄：廉颇（对抗路）、空空儿（打野）、元流之子·刺客（中路）、瑶（游走）、敖隐（发育路）
- 可替换位：来源未给替补位；空空儿被 ban 则体系核心（偷装备）失效
- 体系类型：强开 + 快攻
- 强势期：前期到中期，目标 10 分钟结束比赛，不吃后期
- 为什么强：空空儿能偷对面装备分给队友，团战偷掉对面核心大件等于让对面输出砍半，分身还能骗技能，拉扯能力拉满；元流之子刺客大招减一半全技能冷却，打完一套再打一套连续穿梭进场，低分段根本防不住；廉颇霸体 + 最高 20% 减伤开团三连锤；瑶附身给真实护盾并自动解硬控；敖隐后排补输出
- 反制思路：拖后期（这套越拖越弱）；廉颇开团前打断/拉开身位，抓空空儿与元流之子进场的空窗；针对瑶＝无前排，集火被附身的目标
- 来源：https://m.sohu.com/a/1039015161_122836963/（2026-06-20）
- 置信度：medium（1 源，2026-06）

## 6. 廉颇 + 大乔 + 公孙离 + 镜 + 不知火舞（KPL 经典均衡体系，5 人阵容）
- 核心英雄：廉颇（对抗路）、镜（打野）、不知火舞（中路）、公孙离（发育路）、大乔（游走）
- 可替换位：来源未给替补；核心是「廉颇＋大乔」的开团-保护闭环与「大乔＋公孙离」的下路统治
- 体系类型：开团 + 保护闭环 + 多核
- 强势期：中期抱团推塔最强，后期靠镜单带 + 团战切入
- 为什么强：廉颇与大乔构成「开团 + 保护」闭环，兼具沉默与击飞控制；乔离组合统治下路；不知火舞提供爆发切入；镜兼具后期输出与单带能力，整体结构均衡；KPL 常见换线运营，把射手辅助放中路，便于前期争视野、反野与发起团战
- 反制思路：多核怕被分割，集中火力先掐大乔（二技能一断，乔离的越塔与续航就崩）；限制公孙离的操作空间；用强开阵容逼团队站位
- 来源：https://game.zol.com.cn/1082/10822585.html（2025-11-24；文中标注该阵容为 2019/2020 巅峰之夜经典阵容）
- 置信度：medium（1 源；2025 年复盘文引用的旧经典，非当前版本强度榜）

## 7. S40 抢 T0 英雄五排阵容（5 人阵容）

- 体系类型：T0 强度堆叠（非机制体系，靠英雄强度）

## 10. 强开收割流（4 人框架 + 中路自由位）
- 核心英雄：廉颇（对抗路）、澜（打野）、敖隐（发育路）、瑶（游走）；中路来源未指明
- 可替换位：中路任选；瑶可换其他能保人的软辅
- 体系类型：强开 + 收割
- 强势期：廉颇成型后的中期；前期靠廉颇容错兜底
- 为什么强：廉颇技能全程霸体、最高 20% 减伤，一技能突进接大招三连锤容易击飞后排两三人；澜机动性高、对残血有额外真伤，等廉颇控住后从侧面进场收割；敖隐普攻增强后有龙魂机制，大招不可选中，站后排输出容错高；瑶附身给真实护盾 + 自动解硬控 + 一技能探草，低分段很难拆
- 反制思路：廉颇开团脱节时集火；低分段很少能处理双抗前排，但真伤（吕布、貂蝉一类）仍是解法；廉颇不要提前开团，等敖隐到位

- 强势期：前期靠守塔，鲁班七号成型后一波团可翻盘（中后期）

## 13. 真香（孙尚香 + 太乙真人，2 人组）
- 核心英雄：孙尚香（发育路）、太乙真人（游走）
- 可替换位：无（「真香」即固定二人组）；太乙真人 ban 率与登场率都低，容易拿到
- 体系类型：经济压制 + 保命（半个四保一）
- 强势期：全期；前中期靠转线经济领先，后期靠复活容错
